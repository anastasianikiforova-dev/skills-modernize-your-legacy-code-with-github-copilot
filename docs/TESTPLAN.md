# Student Account Application Test Plan

This test plan describes the current behavior of the COBOL student account application. It is intended for business stakeholder validation before and during migration to Node.js.

**Execution guidance:** Run the cases in isolation unless a case explicitly depends on a previous case. Record observed behavior in `Actual Result`, then set `Status` to `Pass` or `Fail`. `TBD` values are intentionally left blank for test execution.
